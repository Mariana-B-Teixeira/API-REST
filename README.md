# API REST - Laravel (FamousBooks)

Desenvolvimento de uma API REST utilizando Laravel e PHP, realizada para entrega de projeto em Linguagem de Programação IV na Fatec de Praia Grande.

## ☕ Sobre o Projeto

Este projeto consiste no desenvolvimento do backend para um sistema de gestão de livros famosos, permitindo operações completas de CRUD (Criar, Ler, Atualizar e Apagar) integradas com uma base de dados.

## 💻 Tecnologias Utilizadas

- PHP
- Laravel
- SQLite
- Thunder Client (para testes de API)
